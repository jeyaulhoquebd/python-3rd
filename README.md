## 🚀 প্রোগ্রামসমূহ

### 1️⃣ **আয়তক্ষেত্রের ক্ষেত্রফল** (`area.py`)

আয়তক্ষেত্রের দৈর্ঘ্য এবং প্রস্থ দিয়ে ক্ষেত্রফল নির্ণয় করে।

**ফিচার:**
- ব্যবহারকারী ইনপুট গ্রহণ করে
- ফ্লোটিং পয়েন্ট সংখ্যা সমর্থন করে
- সহজ ��বং বোধগম্য ফাংশন

**ব্যবহার:**
```bash
python area.py
```

**উদাহরণ:**
```
Enter Length: 10
Enter Width: 5
The area of rectangle is: 50.0
```

---

### 2️⃣ **ফ্যাক্টোরিয়াল গণনা** (`factorial.py`)

রিকার্সিভ ফাংশন ব্যবহার করে একটি সংখ্যার ফ্যাক্টোরিয়াল নির্ণয় করে।

**ফিচার:**
- রিকার্সিভ অ্যালগরিদম ব্যবহার করে
- নেতিবাচক সংখ্যার জন্য ত্রুটি পরিচালনা
- দ্রুত এবং দক্ষ গণনা

**ব্যবহার:**
```bash
python factorial.py
```

**উদাহরণ:**
```
Enter a positive number: 5
The factorical of  5 is: 120
```

**রিকার্সন ফর্মুলা:**
```
n! = n × (n-1)!
0! = 1
```

---

### 3️⃣ **ত্রিভুজের ক্ষেত্রফল** (`triangle.py`)

হেরন সূত্র (Heron's Formula) ব্যবহার করে ত্রিভুজের ক্ষেত্রফল নির্ণয় করে।

**ফিচার:**
- তিনটি বাহুর দৈর্ঘ্য দিয়ে ক্ষেত্রফল গণনা করে
- ত্রিভুজের বৈধতা যাচাই করে
- গাণিতিকভাবে সঠিক ফলাফল প্রদান করে

**ব্যবহার:**
```bash
python triangle.py
```

**উদাহরণ:**
```
Enter the value of a : 3
Enter the value of b : 4
Enter the value of c : 5
The area of this Triangle is : 6.0
```

**হেরন সূত্র:**
```
s = (a + b + c) / 2
Area = √[s(s-a)(s-b)(s-c)]
```
